# Mind-Map adalah view atas model Item yang sama (Mode Peta: Global/Per-Board = filter view)

Node pada Peta adalah Item itu sendiri (bukan salinan data). Koneksi antar Item disimpan global di `item_edges` (tidak terikat board). Posisi node disimpan di `node_positions(item_id, x, y)` — selalu satu ruang koordinat bersama, **tanpa `board_id`**. Mode Peta (Global = semua Item di satu kanvas; Per-Board = tiap Board/Idea kanvas sendiri yang menampilkan subset Item miliknya) adalah cara memfilter tampilan, bukan struktur data — pola yang sama dengan Mode Inbox (ADR-0002). Mode dipilih di dialog **Setup Awal** saat Board/Idea pertama dibuat (ADR-0009, bawaan Satu Papan Global) dan bisa diganti kapan saja lewat dropdown di area Peta. Karena mode hanya re-filter tampilan, beralih mode tidak pernah menghapus atau memigrasi data, dan posisi node tetap utuh. Struktur ini mencegah duplikasi item dan menjaga sinkron antar view.
