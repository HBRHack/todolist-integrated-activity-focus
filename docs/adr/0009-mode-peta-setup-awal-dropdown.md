# Mode Peta ditentukan di Setup Awal Board/Idea, diganti via dropdown di area Peta

Saat user membuat Board/Idea pertama (klik "+"/Tambah), muncul dialog Setup Awal yang menawarkan pilihan Mode Peta: **Satu Papan Global** (bawaan, semua Item dalam satu kanvas) atau **Multiple Papan** (tiap Board/Idea kanvas sendiri). Pilihan tersimpan persisten di `app_settings`; dialog hanya muncul sekali untuk board pertama — board berikutnya dibuat langsung sesuai mode yang sudah terkunci. Mode bisa diganti kapan saja lewat dropdown Mode Peta yang ada di area view Peta (bukan di menu Settings global). Karena mode hanyalah filter view (ADR-0004), perpindahan seketika dan tidak pernah menghapus/memigrasi data. Alternatif menempatkan kontrol di menu Settings global ditolak: keputusan ini bersifat per-project dan paling wajar diputuskan saat user membuat Board/Idea barunya sendiri.
