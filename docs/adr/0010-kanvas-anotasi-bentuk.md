# Anotasi Peta (Bentuk) disimpan terpisah dari Item di tabel `canvas_shapes`

Bentuk (kotak, lingkaran, segitiga, garis/panah, coretan bebas) yang digambar di kanvas Peta adalah **anotasi visual** — beda sifat dari Item (Task/Note): shape murni visual, tidak mengalir ke Kanban/List/Kalender, sedangkan Item adalah data hidup. Karena itu shape **tidak pernah** masuk tabel `items`; ia disimpan di tabel baru `canvas_shapes` (migrasi `PRAGMA user_version` 3→4) dengan skema: `id, board_id, type, x, y, width, height, rotation, points, style, created_at, linked_item_id`. `board_id` nullable — `NULL` berarti anotasi mode global (Semua), konsisten dengan filter `MapProxyModel` (`-1` = semua board); `ON DELETE CASCADE` ke boards sehingga hapus Board ikut menghapus anotasinya, tidak seperti Item yang kembali ke Inbox (ADR-0008). `points` menyimpan titik coretan/garis sebagai JSON **ternormalisasi 0..1** terhadap kotak pembatas, sehingga resize tidak mengubah data titik. `style` menyimpan **kunci token tema** (mis. `{"stroke":"border","fill":"surface"}`), bukan hex — Bentuk ikut berganti warna saat user ganti preset tema, konsisten dengan PRD §10. Kolom `rotation` merupakan tambahan dari spesifikasi awal (yang disetujui user) untuk mendukung handle rotasi.

**Sifat data Bentuk itu fleksibel — dua kehidupan.** Bentuk lahir dan hidup di entitas terpisah (`canvas_shapes`), bukan di tabel data task; selama itu ia murni **Anotasi Peta** dan tidak pernah muncul di Kanban, List, maupun Kalender. Namun Bentuk bisa di-**Mengonversi** menjadi Item sungguhan kapan saja: `convertShapeToEntity` membuat baris Item di tabel `items` (board = board Bentuk, mode global → Inbox, posisi node = tengah Bentuk) dan mengisikan `linked_item_id` pada Bentuk (FK ke `items` dengan `ON DELETE SET NULL`) — sejak itu Bentuk mengalir ke bagian To-Do List seperti Item lain, sementara Bentuknya sendiri masuk state terkunci (tidak bisa diedit/di-convert ulang). Sifatnya tidak permanen: menghapus Item dari view lain tidak menghapus Bentuk — `linked_item_id` jadi NULL dan Bentuk kembali menjadi Anotasi Peta bebas; sebaliknya menghapus Bentuk tidak menghapus Item (arsitektur relasi, bukan kepemilikan).
